# 两批选择性同步实施计划

> **For agentic workers:** 按工作线并行开发；每个共享入口只有一个集成人。`- [ ]` 表示尚未通过，不是现有能力。

**Goal:** 在 3.5.1 定制基线上同时推进两批功能，按真实入口而非移入的文件验收。

**Architecture:** 工作线各自交付最小闭环和复现用例；集成人串接请求生命周期、路由、权限、数据库和双端导航。外部服务用本机替身测协议，不使用生产账号、数据或站点。

**Tech Stack:** Rust/Axum、SQLite、React/TypeScript、Node 行为测试；定时任务使用 QuickJS，社区提供商使用独立 Bun 运行时。

**Spec:** [两批上游选择性同步：实施边界](../specs/2026-11-27-parallel-sync.md)。下文 `S/` 是 `desktop-tauri/src-tauri/server/src/server/`，`I/` 是 `desktop-tauri/ui-islands/src/islands/`，`M/` 是 `desktop-tauri/mobile/src/pages/`。`scripts/test-sync360-*.mjs` 为拟新增测试。

## 全局约束与评审重点

- 每个切片先让针对新增行为的测试在 `728fdd04` 失败，再在同一测试条件下验收候选；保留原作者与来源。既有混合草稿只读，不复制整份配置、构建产物或共享模块。
- 一切模型请求先走定制的公开路由组和 Key/账号/模型作用域；管理写入拒绝网关 Key。估算价格不是原有渠道倍率或 `credit`。不动 Docker/GHCR 发布契约和 3.5.1 版本。
- 特别评审：跨账号保密词还原；图像跨 Key 读结果；OAuth 回调被另一浏览器消费；后台任务回显凭证到备份；真实零费用在报表中变成未知。各用例由下列相应工作线负责。
- 新建/旧库迁移、异机换钥、并发取消、代理失效禁止回退直连是集成门，不在每个模块单独发明策略。源码编译、双端实际操作和外部真实服务验收分别记录。
- B2/B3 另断言命中后目标无权或失效时不会改投原始模型、视觉失败不会泄露原图；B4 断言实际模型价优先、汇率变化不静默重算旧记录；B6 以至少一套 Linux 隔离宿主实跑固定 Bun 插件为门槛。详见设计的“三个实现决策”。
