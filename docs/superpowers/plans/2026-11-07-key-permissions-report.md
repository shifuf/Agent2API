# 网关 Key 与渠道删除权限跟进

## 实现

- 网关 Key 的渠道未勾选时展示全部手动发布模型；选定渠道时展示关联模型并保留已保存的旧限制。
- 已删除渠道保持在原 Key 的白名单中，标记为已移除。新建 Key 无法选择已删除渠道；编辑原 Key 可以保留或明确移除该限制。
- 删除渠道不再清空任何 Key 的限制，避免最后一项消失后变成全渠道授权。
- 路由组的预览、公开模型和 Key 候选共用账号凭证与 Key 分组模型可用性判断。无凭证、停用分组和未选择上游模型的成员不会提供该路由组。
- `core/managed_models.rs` 的路由组选项循环已改为调用共享检查，该文件由主任务提交。
