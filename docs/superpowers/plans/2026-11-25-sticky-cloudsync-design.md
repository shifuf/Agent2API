# 粘滞与每日云备份修复设计

版本保持3.5.1，目标origin/beta，不推main，不打tag或Release。保留上游定制和生产数据。

粘滞：未完整响应的future/stream Drop记失败，面板显式取消豁免；首次失败优先同渠道其他可用账号，连续第二次冻结并解绑渠道。只改变后续选路，不在已提交或部分输出的同次请求重放。RAII只处理已实际发出的attempt，终态只计一次，保留权限、冷却、generation过滤。

自动备份：每天一次（UTC+8日期），当日新增账号ID补传；用量/余额/token刷新不触发重复上传。成功状态持久化并按目标scope隔离；失败有退避。定时唤醒确保无变更也跨日备份。手动上传即时。现有latest协议保留，history/YYYY-MM-DD每天一套，当天补传覆盖，只删除应用拥有且超过最近七日的历史。manifest最后提交，失败不标成功；下载后hash口径一致。移除桌面和移动Agent配置页面入口，保留共享工具服务。

验收：真实跨请求auto/strict账号轮询与三种Drop、显式取消、完整EOF；可控时间测试日内/跨日/新增ID/等数量替换/重启/失败/目标切换；DAV/S3历史安全边界和完整artifact校验。
