# 定制版上游同步约定

本仓库是 `shifuf/Agent2API` 的定制版。更新来源为 `aimod-cc/Agent2API`，日常集成落在 `beta`。

用户授权的原则：选择性吸收上游改进，保护已有定制功能；上游实现更好且兼容时，可依据代码和测试采用。每次推送仍以当次用户授权和 release-flow 为准。

## 每次更新的流程

1. 检查工作区和当前提交，分别 fetch `origin`、`upstream`，记录两个上游分支的提交。不把“上次查看过”当成“已经全部合入”。
2. 对照本文件的记录逐项判断：完整采纳、适配后采纳、已实现、暂缓。先查依赖，再选择提交或补丁；不能用整体覆盖、`ours`/`theirs` 或伪造合并记录掩盖未审查改动。
3. 在隔离工作区处理，保留来源提交和作者署名。修改公共接口时同时验证定制调用方；生成的前端文件应从本仓库源文件构建。
4. 运行所选补丁的行为测试及受影响的定制回归。上游实现要替换已有实现，必须说明收益、兼容方式和测试证据。
5. 更新本文件的同步记录，再按授权推送 `origin/beta`。推送后核对 Docker 构建、双架构镜像及镜像的源码 revision。未经授权不改版本、不打 tag、不创建 Release。

## 必须保护的功能

- 路由组统一管理对外模型 ID（含大小写），对话和生图/编辑都可用；保留账号、Key、模型 ID 的迁移与作用域限制。
- 模型管理用于查看、获取、选择和测试上游模型；保留内置提供商及自定义提供商、账号、Key 分组的显式模型选择，不恢复两处创建同名对外模型的流程。
- AxonHub 风格的账号/Key 选择、厂商模型目录，以及 Magpie 风格的路由界面、彩色图标。
- 仅管理员可主动查看账号密钥；普通快照继续脱敏，网关 Key 不能调用密钥详情接口。
- 提供商倍率显示，未知与零倍率有区别；不擅自改变路由计费语义。
- 代理订阅及其内核生命周期、Grok 工具 schema 的 `required` 数组兼容。
- 本仓库的 Docker 自动构建、GHCR 镜像位置、关闭上游自更新的部署配置，及桌面/手机端对应功能。
- 使用临时数据测试，不以真实账号库做迁移、恢复或凭据回归。
