# 性能与模型溯源验收记录

范围：按照用户“先性能，特别是版本信息，2 核 2GB；然后模型溯源”的授权，本地修改 beta。未改版本号，未提交、推送或发布；Magpie 插件兼容暂缓。

## 已修改

- 设置只读当前分类，在途读取合并。隐藏的系统信息、云同步、更新令牌和插件管理面板不在版本页读取。分类切回保留未保存配置；整页刷新仍重新读取。脱敏切换清除旧路径并拒绝过期响应。
- 系统诊断移到 blocking 线程；请求/日志只计总数，账号不构造公开列表，模型不补齐 metadata 与能力覆盖，schema 从现有连接读取。
- 请求列表计数使用 WHERE 和既有索引；事件日志使用游标逐条归一与筛选，保留 Unicode 关键词及旧插件分类语义，只有当前页保存完整条目。日志读取和正文读取移出异步工作线程。
- 隐藏路由页暂停秒级时钟更新，隐藏账号页跳过列表重渲染。
- 详情首屏使用元数据。正文按访问标签读取，离开标签卸载正文 DOM；预览预算为 256Ki 字符/节点量级，大正文不进入 Markdown。原文显示限制 256Ki 字符，复制仍获取已保存全文，HTTP 面板保留剪贴板回退。历史已截断正文继续提示。
- 原始响应流在协议转换和模型名回写前采集模型，按尝试保存 `responseModels` 与 `responseModelSource`，无需数据库 schema 迁移。支持 Chat `model`、Responses `response.model`、Anthropic `message.model`、Gemini `modelVersion` / `response.modelVersion`。插件声明标记为 `plugin`，不冒充直连原始上游证据。详情显示发送/响应模型、名称差异和路由原因。

## 剩余边界

- 未在用户服务器上做长时间 RSS/堆快照压测，不能声称所有卡死或内存泄漏已经消除。
- 开启调试时转发链仍缓冲完整正文；原始正文详情下载仍返回完整内容。关闭详情会卸载 DOM、丢弃迟到响应，但尚未取消已发出的正文下载。流式落盘、分段下载需要后续独立改造。
- 日志分页不再保留全部历史正文，但当前页某一聚合组内的全部条目仍保留，极大组仍可能占用较多内存。
- 模型采集每事件最多 256KiB、每轮最多八个不同名称，每个名称最多 512 字节；超出预算或未返回模型字段时可能无证据。前端使用“未采集到”，不以请求模型冒充。
- 响应名称只是上游或插件声明，不能鉴定实际权重。插件可能已归一模型名称，页面明确标注来源。旧记录不能补造，未接入的响应路径保留缺失。
- 账号页可见时仍按原刷新频率工作，未实施全站虚拟列表或前端分包。
